# Design Direction

## Final Direction

The final visual direction is:

**Forecast Passport / Travel Brief**

The page should feel like a premium personal weather brief instead of a generic weather dashboard.

The main design goal is to make the recommendation feel more important than the raw weather numbers.

## Core Design Rule

**The weather data supports the decision. The recommendation is the answer.**

The user should be able to understand what to wear and what to bring before studying the individual forecast values.

---

# Colors

## Paper

`#F6F3EA`

Use as the main page background.

It should feel warm and slightly editorial rather than bright white.

## Ink

`#16202A`

Use for:

- Main text
- Headlines
- Major borders
- Important forecast values

## Muted

`#66717C`

Use for:

- Supporting explanations
- Secondary information
- Metadata
- Small labels

## Navy

`#18324A`

Use for:

- Main buttons
- Strong interactive emphasis
- Important structural elements

## Blue

`#2F6F8F`

Use selectively for:

- Section labels
- Important weather emphasis
- Focus states

## Blue Soft

`#DBE9EF`

Use for the supporting weather-data panel.

Do not use it as a large decorative background elsewhere.

## Warm Accent

`#B86F3C`

Use sparingly for:

- Small important labels
- Preparation / attention sections

The warm accent should remain secondary to Navy and Blue.

---

# Typography

Use system fonts only.

## Main Editorial Font

Use:

```text
Georgia, "Times New Roman", serif
```

Use for:

- Hero headline
- Main recommendation
- Location
- Supporting editorial text

## Interface Font

Use:

```text
Arial, Helvetica, sans-serif
```

Use for:

- Labels
- Buttons
- Forecast values
- Form controls
- Footer
- Metadata

Do not load an external font.

---
